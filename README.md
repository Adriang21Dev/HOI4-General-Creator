# HOI4 General Creator

Herramienta gratuita para crear mods de generales para Hearts of Iron IV.

## Características

- Creación de generales a partir de retratos `.dds`.
- Configuración de ataque, defensa, planificación y logística.
- Generación manual de generales.
- Generación aleatoria.
- Generación aleatoria con rasgos personalizados.
- Soporte para rasgos personalizados.

## Requisitos

- Windows
- Hearts of Iron IV

## Uso

Descarga la versión disponible en **Releases** y ejecuta `HOI4 General Creator.exe`.
